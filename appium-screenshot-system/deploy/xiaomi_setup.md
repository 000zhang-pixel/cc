# 小米手机 USB 调试配置指南

## 第一步：开启开发者模式

1. 打开「设置」→「我的设备」→「全部参数与信息」
2. 快速连续点击「MIUI 版本」7 次
3. 提示「您已进入开发者模式」

## 第二步：配置开发者选项

进入「设置」→「更多设置」→「开发者选项」，依次开启：

| 选项 | 操作 | 说明 |
|------|------|------|
| USB 调试 | ✅ 开启 | Appium 连接必需 |
| USB 调试（安全设置） | ✅ 开启 | 允许修改权限/截图 |
| 禁止权限监控 | ✅ 开启 | 减少 MIUI 权限弹窗干扰 |
| 关闭 MIUI 优化 | ✅ 关闭优化 | 提升自动化兼容性 |
| 不锁定屏幕 | ✅ 开启 | 防止测试中途熄屏 |
| 动画过渡效果 | 设为 0.5x 或关闭 | 加快 UI 响应速度 |

> ⚠️ MIUI 版本 ≥ 12 需要同时开启「USB 调试」和「USB 调试（安全设置）」，缺一不可。

## 第三步：连接 Mac

1. 用原装 USB 线（或品质好的数据线）连接手机和 Mac
2. 手机弹出「USB 连接方式」→ 选择「**文件传输（MTP）**」
3. 手机弹出「允许 USB 调试」→ 勾选「一律允许」→ 点击「确定」

## 第四步：验证连接

在 Mac 终端运行：

```bash
adb devices
```

正常输出：

```
List of devices attached
abc123def456   device     ← 显示 device 表示成功
```

> 如果显示 `unauthorized`：手机上会重新弹出「允许 USB 调试」弹窗，点击「允许」即可。

## 第五步：运行校准

```bash
bash deploy/calibrate.sh --android xiaohongshu
```

## 常见问题

**Q: `adb devices` 显示 `offline`**
→ 拔掉 USB 重新插，手机重新弹窗选「文件传输」并允许 USB 调试

**Q: Appium 报错 `An unknown server-side error occurred`**
→ 检查小红书/抖音是否已安装在手机上

**Q: 采集过程中出现权限弹窗导致失败**
→ 开发者选项中开启「禁止权限监控」，或在 settings.yaml 设置 `auto_grant_permissions: true`

**Q: MIUI 自动把 Appium 会话杀掉**
→ 手机「安全中心」→「授权管理」→ 找到目标 App → 关闭「自启动限制」

**Q: 截图全黑 / 无法截图**
→ 开发者选项中开启「USB 调试（安全设置）」
