## 1. 人设 Prompt 模板全量补全（16 条）

### 根因

`_build_image_master_prompt` 和 `_build_image_sub_prompts` 在 `prompt_template` 存在时，
走了独立分支，完全跳过了 `style`（穿搭风格）和 `action`（动作倾向）字段注入。

### 修复：代码（commits d6989bc、b24ec80）

在 `prompt_template` 分支中补注入 `style` + `action`：

```python
# _build_image_master_prompt（修复前）
if _persona_prompt_template:
    person_part = ["", f"【人物】{_persona_prompt_template}"]

# 修复后（b24ec80）
if _persona_prompt_template:
    _style   = (persona or {}).get("style", "").strip()
    _posture = (persona or {}).get("action", "").strip()
    _extra_parts = [x for x in [_style, _posture] if x]
    _extra_str = "，" + "，".join(_extra_parts) if _extra_parts else ""
    person_part = ["", f"【人物】{_persona_prompt_template}{_extra_str}"]
```

## 2. style 冗余去除 + 外貌质量标准恢复（commit d62641a）

### 问题

第 1 步修复后，`prompt_template` 已包含英文服装描述，但代码仍追加中文 `style` 字段，
形成双语重复。同时，场景表 `外貌风格`（"真实感/无过度美颜修图"）在有 template 时被丢弃。

### 修复：代码

```python
# _build_image_master_prompt（修复后）
if _persona_prompt_template:
    # action 提供具体姿态指令；style 已内嵌于 prompt_template
    _posture = (persona or {}).get("action", "").strip()
    _extra_str = "，" + _posture if _posture else ""
    person_part = ["", f"【人物】{_persona_prompt_template}{_extra_str}"]
    # 场景外貌风格质量标准：富描述（>12字）时注入为 人物质感 行
    if appearance and len(appearance) > 12:
        person_part.append(f"人物质感：{appearance}")

# _build_image_sub_prompts（修复后）
if _sub_prompt_template:
    # 质量标准已在 master_prompt 注入，sub 只追加动作
    _posture = (persona or {}).get("action", "").strip()
    _extra_str = "，" + _posture if _posture else ""
    person_suffix = f"，画面中有{person_type}（{_sub_prompt_template}{_extra_str}）"
```
