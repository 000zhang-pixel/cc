## ADR-001：飞书表格创建方式

**日期**: 2026-04-03
**状态**: 已决定

**背景**: 需要创建6张多维表格，字段较多（每张15-20+字段）。

**选项**:
- A. 手动在飞书界面创建
- B. 通过飞书API自动创建

**决定**: B — API自动创建
**理由**: 手动建表容易出错且耗时；API创建结构即代码，版本可控，字段调整方便。

## ADR-003：场景组合控制层级

**日期**: 2026-04-03
**状态**: 已决定

**背景**: 每组图片需要多场景/多角度/多道具/多光影组合，需决定在哪个层级控制。

**选项**:
- A. 在内容规划表手动指定场景
- B. 预设场景标签多选
- C. 全部交给AI提示词引擎

**决定**: C — 提示词引擎通过「场景库策略 + 产品属性」自动匹配，内容规划表不涉及场景字段。
**理由**: 保持规划表简洁，场景库后期可独立扩充，不影响规划层。

## ADR-004：实拍类任务AI文案与素材的关联关系（第一阶段）

**日期**: 2026-04-03
**状态**: 已决定

**背景**: 图片实拍/视频实拍+AI文案任务，需决定AI文案是否关联实拍素材。

**决定**: 第一阶段，实拍类任务AI文案**仅关联SKU属性信息**，不关联实拍图片/视频。实拍素材由发布侧自行处理。
**理由**: 简化第一阶段实现复杂度；实拍素材管理属于独立问题。

## ADR-007：本地存储三区设计

**日期**: 2026-04-07
**状态**: 已决定

**背景**: 原始存储结构（`storage/workspace/`）职责不清晰，发布后内容残留工作区，目录命名对开发者不直观。

**决定**: 将本地存储重构为三个职责明确的区域：

```
content-store/
├── inbox/            ← 原始素材输入区（用户手动放入实拍图片）
├── Pending_Content/  ← 生成内容工作区（系统读写，发布引擎读取）
└── archive/          ← 发布归档区（发布成功后自动移入）
```

**关键实现**:
- `LocalStorage.archive_content(plan_code, group_id)` — 发布成功后自动 `shutil.move` 到 `archive/{year_month}/`
- `content-store/` 加入 `.gitignore`，不进入 Git 版本管理
- 路径通过 `LOCAL_STORAGE_ROOT` 环境变量配置，代码无平台判断逻辑

## ADR-008：双平台运行策略（Windows + Mac）

**日期**: 2026-04-07
**状态**: 已决定

**背景**: 用户需要在 Windows（主力生产）和 Mac（内容查阅、ADB发布）两端运行同一套系统。

**决定**:
- **代码同步**: GitHub（`git pull/push`），`content-store/` 排除在外
- **内容文件同步**: Syncthing，仅同步 `content-store/` 目录（图片/视频/json/txt）
- **路径配置**: Windows `.env` 用 `D:/AI-Content-Hub/content-store`；Mac `.env` 用 `/Users/carson/openclaw/workspace/content-store`
- **Python 代码**: `local_storage.py` 内置平台默认路径（`platform.system()` 检测），`.env` 可覆盖

**Mac 路径**: `~/openclaw/workspace/AI-Content-Hub/`（与 Windows 代码库保持同名）

## ADR-009：发布引擎跨平台改造

**日期**: 2026-04-07
**状态**: 已决定

**背景**: `publish_engine_v40.sh` 原为 Windows Git Bash 专用，含 Windows 特有代码，无法在 Mac 直接运行。用户确认 Mac 上 ADB 发布已测试成功。

**改造方案**:
- 顶部 `uname -s` 检测平台，设置 `PLATFORM=windows/mac/linux`
- 封装 `_adb()` 函数：Windows 加 `MSYS_NO_PATHCONV=1`，Mac 直接调用
- 剪贴板：Windows 用 `powershell.exe Set-Clipboard`，Mac 用 `pbcopy`
- 弹窗检测超时：Windows 用 PowerShell Process.WaitForExit，Mac 用 `timeout 12 adb ...`
- 临时文件路径：统一改为 `/tmp/`（Mac/Linux 通用）
- adb PATH：Mac 自动查找 `~/Library/Android/sdk/platform-tools` 或 Homebrew

## ADR-010：标签分层随机选取规则

**日期**: 2026-04-07
**状态**: 已决定

**背景**: 原规则直接取权重排名前 N 的标签，导致高权重标签被反复使用，标签多样性不足。

**决定**: 将标签池分为两层，按比例随机取：

| 层 | 范围 | 比例 |
|----|------|------|
| 头部池 | 权重排名 **前 20** | **60%**（`round(n×0.6)`） |
| 长尾池 | 权重排名 **第 11 名之后** | **40%**（`n - round(n×0.6)`） |

**去重规则**: 11-20 名是两个池子的重叠区间，用 record_id 去重，同一标签不重复选取。

**实现位置**: `middleware/handlers/content_generation.py` → `_fetch_tags()`

**示例（n=5）**:
- `n_top = round(5×0.6) = 3` → 从前20随机取3个
- `n_tail = 5 - 3 = 2` → 从第11名之后随机取2个
