# 图片生成提示词框架（定稿 2026-04-19）

## 框架总结

每张图片的最终 prompt = **master_prompt** + `---` 分隔符 + **sub_prompt**，
拼接后整体发送给图片生成模型（Gemini）。

```
{master_prompt}

---

{sub_prompt}
```

---

## master_prompt 结构

由 `_build_image_master_prompt()` 构建，目标长度 ≤600 字。

```
【产品】{产品简称}，{颜色}色，{材质}材质，{风格}风格
【挂接规范】手机链通过手机壳底部中间挂绳孔或侧边孔穿入固定，链条自然垂坠于手机下方或侧方，比例协调，挂接处自然无穿帮，链条长度约为手机高度的1/2至等长，不拉扯变形

【场景】{场景描述_中文}
风格：{风格基调词}。情绪：{情绪基调}。

【人物】{Prompt描述模板}，{动作倾向}
人物质感：{外貌风格}          ← 仅当场景外貌风格 >12字时注入

【道具参考】{道具建议}         ← 可选，超出预算时丢弃

【技术参数】{光线方向}、{色温}、{景深感}、{镜头感}  ← 可选，超出预算时丢弃

【一致性要求】
- 所有图片保持完全相同的产品外观（颜色、材质、细节）
- {consistency_template}（来自 Persona）或"同一人物（同款服装/发型）"
- 统一光线和色彩风格贯穿始终
- 【强一致性】人物面孔/发型/服装禁止漂移，产品细节禁止变化

【避免】{排除描述}             ← 可选，超出预算时截断或丢弃
```

### 预算超出时的丢弃顺序

1. 丢弃 `【技术参数】`
2. 丢弃 `【道具参考】`
3. 截断 `【避免】` 至第一个分句
4. 丢弃 `【避免】`
5. 最后兜底：截断 `【场景】` 至 60 字

## sub_prompt 结构

由 `_build_image_sub_prompts()` 构建，每张 ≤200 字，共 N 张（对应 img_count）。

**来源优先级**：ShotPlan 拍摄方案表 > 默认 6 个通用镜头角色（正面/细节/上手/侧后/平铺/融合）

```
{拍摄角色描述}，{场景描述片段}，画面中有{人物类型}（{Prompt描述模板}，{动作倾向}）
【一致性约束】{consistency_template}；人物面孔/发型/服装禁止漂移，产品细节禁止变化
```

---

## 人物描述字段优先级

| 场景 | 使用字段 |
|------|---------|
| 有 Persona 且有 `Prompt描述模板` | `Prompt描述模板`（英文） + `动作倾向`（中文）；场景 `外貌风格`（>12字）作为 `人物质感` 补充 |
| 有 Persona 但无 `Prompt描述模板` | Persona 的 `性别倾向`、`年龄段`、`外貌风格`、`动作倾向`（场景字段兜底） |
| 无 Persona（scene_fallback） | 场景表的 `性别倾向`、`年龄段`、`外貌风格`、`姿态倾向` |

---

## Persona Prompt描述模板 写作规范

英文，覆盖以下维度，不超过 2 句话：

```
Asian girl, approximately {年龄} years old, {发型特征}, {妆容风格},
{人设气质}, {具体服装单品（来自穿搭风格字段）},
{表情/眼神关键词（青春感/活力/自然笑容）}.
```

**必须包含**：
- 服装单品（具体款式，而非笼统"时尚"）
- 表情/眼神活力词（bright eyes / natural smile / energetic / youthful glow 等）
- 人设标志性气质词

**禁止**：
- gift-unboxing / gift box / packaging 等礼盒词汇
- 超出 3 句话（prompt 预算有限）

---

## 场景 外貌风格 字段规范

| 人物类型 | 外貌风格值 |
|---------|-----------|
| 有人物·主体 | 完整质量标准：`年轻亚洲女性，身材比例好，精致五官，自然妆感，无过度美颜无过度修图` |
| 有人物·局部（手/腕） | 可留 `不指定`（不影响人物质感注入逻辑，因 <12 字自动跳过） |
| 无人物·纯产品 | 随意，不参与 prompt 构建 |

---

## 禁止写入 prompt 的内容

| 类别 | 禁止词 | 原因 |
|------|--------|------|
| 礼盒/包装 | 礼盒、外包装、包装盒、礼品盒、开盒 | 产品无礼盒 |
| 过度美化 | 过度美颜、修图感、美颜相机、完美无瑕 | 与真实感指令矛盾 |
| 角色冲突 | 换装、换人、更换发型 | 一致性约束覆盖场景 |
