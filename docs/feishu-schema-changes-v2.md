# 飞书表结构变更说明 — Prompt 系统升级 v2

**对应 PRD**：`docs/prd/prompt-system-upgrade-v1-2026-04-17.md`  
**变更日期**：2026-04-18  
**状态**：待运营在飞书手动创建/修改字段

> 所有新增字段均为**可选增强项**，若未建立，系统将自动回退到旧逻辑，不影响现有任务生成。

## 一、表2 — 内容规划表：新增字段

> 在现有触发字段之后，追加以下 4 个可选控制字段。

| 字段名 | 类型 | 选项值 | 默认值 | 说明 |
|--------|------|--------|--------|------|
| 差异化强度 | 单选 | 低 / 中 / 高 | 中 | 控制多组内容的叙事角度拉开幅度 |
| 人设模式 | 单选 | 自动 / 固定主人设 / 多人设轮换 | 自动 | 控制 Persona 分配方式 |
| 一致性强度 | 单选 | 中 / 强 | 强 | 控制组内图片一致性约束力度 |
| 场景丰富度 | 单选 | 低 / 中 / 高 | 中 | 影响场景切换幅度（供后续扩展） |

## 四、表8 — 内容策略表 Strategy：新增字段

> 用于提供更丰富的差异化模板，均为可选，旧字段保持不变。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 叙事角度标签 | 多选 | 搭配点睛 / 日常实用 / 细节质感 / 氛围感种草 / 礼物推荐 |
| 结构模式 | 单选 | 场景切入 / 痛点切入 / 体验切入 / 对比切入 / 情绪切入 |
| 标题句式池 | 多行文本 | JSON 数组，如 `["疑问句式","数字/对比句式","反转句式"]`；有值时代替代码内置硬编码 |
| 正文禁忌 | 多行文本 | 禁止出现的表达，如"强烈推荐"/"买不了吃亏"等广告腔 |
| 差异化提示模板 | 多行文本 | 自定义篇次差异化提示，支持 `{group_index}` `{total_groups}` `{title_pattern}` `{narrative_angle}` 占位符 |
| 人设适配标签 | 多选 | 该策略适合哪些 persona 气质（与表12气质标签联动，暂备用） |

**示例：标题句式池**
```json
["疑问句式（如：为什么我…？）","数字/对比句式（如：买了X件才发现…）","场景直述句式","反转/意外句式","情绪共鸣句式"]
```

**示例：差异化提示模板**
```
⚠️ 差异化要求：这是本产品第 {group_index} 篇笔记（共 {total_groups} 篇）。
标题请采用「{title_pattern}」，叙事角度为「{narrative_angle}」，
切入角度必须与其他篇次明显不同，禁止重复开头词或叙事骨架。
```

## 七、表12 — Persona 人设模板表（全新建表）

> **新建**。创建后将 `table_id` 填入 `middleware/config/system.yaml` 的 `persona:` 字段。

### 建表字段

| # | 字段名 | 类型 | 说明 |
|---|--------|------|------|
| 1 | 人设编号 | 文本（主键） | 如 PS001、PS002 |
| 2 | 是否启用 | 单选 | 启用 / 停用 |
| 3 | 人设名称 | 文本 | 如：甜酷通勤女生 |
| 4 | 性别倾向 | 单选 | 女 / 男 / 中性 |
| 5 | 年龄段 | 单选 | 18-22 / 22-26 / 26-30 / 30+ |
| 6 | 外貌风格 | 文本 | 如：长发、轻妆、甜酷感 |
| 7 | 穿搭风格 | 文本 | 如：休闲通勤 / 极简时髦 |
| 8 | 气质标签 | 多选 | 甜酷 / 清冷 / 松弛 / 精致 / 青春 |
| 9 | 动作倾向 | 文本 | 如：自然持握、回头、低头看手机 |
| 10 | 适用品类 | 多选 | 手机链 / 手机壳 / 通用 |
| 11 | 适用内容类型 | 多选 | 种草推荐 / 穿搭搭配 / 场景展示 等 |
| 12 | 适合场景标签 | 多选 | 商场 / 校园 / 咖啡馆 / 街头 等 |
| 13 | Prompt描述模板 | 多行文本 | 用于图片 Prompt 的完整人物描述 |
| 14 | 一致性锚点模板 | 多行文本 | 用于组内一致性约束，如"同一女生，长发，轻妆，甜酷风，同套服装，同款发型，相同面孔特征" |
| 15 | 优先级 | 数字 | 同类候选中排序，越高越优先 |
| 16 | 备注 | 文本 | 说明用途 |

### 建表后操作

1. 在飞书新建表后，复制表的 `table_id`（形如 `tblXXXXXXXX`）
2. 编辑 `middleware/config/system.yaml`，将 `persona: ""` 改为实际 table_id
3. 录入至少 3 条人设记录（`是否启用=启用`），覆盖主要气质类型
4. 下次任务触发时自动生效，无需重启 middleware

## 变更优先级建议

| 优先级 | 操作 | 影响 |
|--------|------|------|
| 🔴 高 | 表3 / 表4 新增观测字段 | 立即可用，调试价值高 |
| 🔴 高 | 表8 Strategy 新增 `标题句式池` 和 `差异化提示模板` | 可替换硬编码逻辑 |
| 🟡 中 | 表9 ShotPlan 新增 `禁止重复镜头` / `动作变化要求` | 改善图片组内差异 |
| 🟡 中 | 表10 Scene 新增 `道具建议` | 丰富画面细节 |
| 🟢 低 | 表2 新增 4 个控制字段 | 精细调控，运营按需使用 |
| 🟢 低 | 表12 Persona 新建 | 人设模板系统，需配置后生效 |
