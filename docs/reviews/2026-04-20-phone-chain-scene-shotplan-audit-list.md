## Risks / open questions

1. 本清单基于导出 JSON 文本审计，不是最终成图 A/B 数据审计。
2. `SC042-SC071` 这批人物场景虽然多数可用，但仍需二次清洗外貌/服装描述中的潜在性感化残留。
3. `SP038` 这类“大片感”方案虽然可保留，但必须加商品 KPI，否则仍会滑向氛围优先。
4. Persona 当前最大问题不是数量不足，而是若干旧人设仍带有幼态化、欧美化、运动化残留。
5. Strategy 当前除方向问题外，还有明显“策略名 / 系统提示词前缀 / 节点结构”错位，后续脚本落表前应先做一致性修正。
6. 是否保留少量季节 / 礼物 / 社交货币模板作为 campaign-only 子池，仍需要你拍板；按当前主方向，我建议默认不进入常规候选池。
